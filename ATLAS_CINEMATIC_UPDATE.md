# Atlas Cinematic Visual Overhaul

This branch replaces the flat Atlas treatment with a continuous scroll narrative:

1. Atlas core synthesizes inside a side-profile brain and traces the neural path.
2. The core exits through the brain stem and visually directs the user down-page.
3. The core impacts the seven-stage growth system with shockwaves, flare, and particle dispersion.
4. Growth stages reveal sequentially from the energy event.
5. Particles reform into the Atlas core after stage seven.
6. The reformed core continues downward into a cinematic Atlas introduction.
7. Atlas materializes inside a layered holographic environment with depth planes, orbital rings, scan effects, system panels, and a 3D energy core.

The visual layer uses native React, SVG, CSS 3D transforms, and scroll-driven state to avoid adding heavy runtime dependencies. Reduced-motion fallbacks and mobile layouts are included.
